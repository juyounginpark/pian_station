### GBGC 5팀
# 피안역

## <커밋규칙>
| 유형           | 의미                          | 예시                                           |
| ------------ | --------------------------- | -------------------------------------------- |
| **feat**     | 새로운 기능 추가                   | `feat(ui): add dark mode toggle`             |
| **fix**      | 버그 수정                       | `fix(api): resolve null pointer in response` |
| **docs**     | 문서 수정                       | `docs: update README with setup guide`       |
| **style**    | 코드 포맷, 세미콜론 등 스타일 수정 (로직 X) | `style: reformat playerController.cs`        |
| **refactor** | 코드 리팩토링 (기능 변화 없음)          | `refactor(game): simplify collision check`   |
| **perf**     | 성능 개선                       | `perf(render): reduce draw calls`            |
| **test**     | 테스트 추가/수정                   | `test: add unit tests for player movement`   |
| **chore**    | 빌드, 설정, 의존성 등 자잘한 변경        | `chore: update npm dependencies`             |
| **ci**       | CI/CD 관련 설정 수정              | `ci: fix GitHub Actions build pipeline`      |
| **revert**   | 이전 커밋 되돌리기                  | `revert: feat(auth): add login feature`      |
